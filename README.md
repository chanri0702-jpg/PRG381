# Cleaning Inventory & Issuance System

## Overview
The Cleaning Inventory & Issuance System is a Java web application developed using JSP, Servlets, JDBC and MVC architecture. The system helps manage cleaning materials, suppliers, cleaners, stock issuance and reporting.

## Technologies
- Java
- JSP
- Servlets
- JDBC
- HTML & CSS
- Apache Tomcat 10.1
- Jakarta EE 10
- SQL Database
